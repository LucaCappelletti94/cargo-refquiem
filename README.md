# cargo-refquiem

[![CI](https://github.com/LucaCappelletti94/cargo-refquiem/actions/workflows/ci.yml/badge.svg)](https://github.com/LucaCappelletti94/cargo-refquiem/actions/workflows/ci.yml)
[![crates.io](https://img.shields.io/crates/v/refquiem.svg)](https://crates.io/crates/refquiem)
[![docs.rs](https://docs.rs/refquiem/badge.svg)](https://docs.rs/refquiem)

A cargo requiem for the refs your Rust code left behind.

`cargo refquiem` walks your git history, finds every item, dependency, feature, binary and example that existed in some commit and is gone now, and reports the comments, doc comments, string literals and Markdown files that still name it, from paths, names written alone and rustdoc page links to `--features` flags, `toml` snippets and serde spellings in `json` or `yaml` examples. Named imports resolve item paths, and re-export expansion stops at module cycles.

```sh
cargo refquiem                                   # every commit, against the working tree
cargo refquiem --since v0.3.0                    # from a release on
cargo refquiem --base origin/main --head HEAD    # what a branch removed
```

A name generated by an item-position macro, publicly reachable through a dependency or the standard library, or used as a plain English word in prose counts as alive. Removed dependency APIs are read at the locked version when available, match only full crate-root paths when the crate is entirely dropped, and produce warnings when their sources cannot be resolved. The exit code is `0` when nothing is stale, `1` with findings and `2` on errors, including a failed Markdown reader.

Release histories and generated files are not scanned. A `.refquiem.toml` at the workspace root adds excludes and names that are never reported, and a `refquiem: allow(Name)` comment silences one mention on its own line or the next. A bare `allow` name also keeps serialized spellings alive, and marker text in Markdown code has no suppression effect.

```toml
exclude = ["docs/migration/"]
allow = ["Parser::parse_expr", "structopt"]
since = "v0.3.0"
```
