# Dogfood

This page exists only on the demo pull request, to show every kind of review comment refquiem posts.

Read with `refquiem::fuzzing::mentions`, or call `refquiem::fuzzing::mentions` twice on one line.

Parse with `refquiem::fuzzing::declarations`.

A ```` run of backticks sits beside `refquiem::fuzzing::declarations` here.

Print with `refquiem::Report::human`.

Check `refquiem::Report::is_clean` first.

Then check `refquiem::Report::is_clean` again.

And once more `refquiem::Report::is_clean`.

Last, `refquiem::Report::is_clean`.

Build the fuzz targets with `cargo build --features fuzzing`.
